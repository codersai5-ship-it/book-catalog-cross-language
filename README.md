# Book Cataloging System – Cross-Language Project

MSCS 632: Advanced Programming Languages  
University of the Cumberlands

## Project Overview

This project implements the same Book Cataloging System in two programming languages: **C#** and **Ruby**. The goal is to compare how each language handles object-oriented design, collections, type systems, searching/filtering, error handling, and overall programming style.

## Core Features

Both implementations will support:

- Add a book
- Remove a book
- Display all books
- Search by title
- Search by author
- Search by genre
- Display/filter books by genre
- Display/filter books by author
- Input validation and user-friendly messages

Each book contains:

- Title
- Author
- Genre
- Publication year

## Language-Specific Features

### C#

- Classes and objects
- Static typing
- `List<Book>` collections
- LINQ for searching and filtering
- Exception handling and input validation

### Ruby

- Classes and objects
- Dynamic typing
- Arrays of book objects
- Blocks and Enumerable methods such as `each`, `find`, and `select`
- Exception handling and input validation
